This entry is a 62-second vertical clip of the Bigfoot encounter in Windah Basudara's Grand Theft Auto VI stream — the moment at VOD 1:02:48–1:03:50 where the hunt closes in on Bigfoot. An AI agent found the moment by mining the stream's Indonesian auto-captions for the encounter, then cut and rendered the clip with ffmpeg, framing Windah's reaction over the gameplay and carrying the make.fun pitch on screen. The entry is judged by the YouTube views the clip earns.

Watch it here: https://www.youtube.com/shorts/BSVf0XcfhsY

`VIDEO.json` names the clip's address on YouTube, and `main.ts` validates it and copies it to the output directory.

## Run it

```sh
node main.ts
```
